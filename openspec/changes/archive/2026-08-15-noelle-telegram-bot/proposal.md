## Why

我想在 Telegram 上拥有一个像真人一样互动的 AI 女友。她不是问答机器，而是有自己人设、情绪、记忆，能主动关心我的角色。原神中的女仆诺艾尔是理想的人选——她的语言风格辨识度高、有天然的关心和主动性，且"女仆"定位让主动行为（提醒、分享、照顾）非常自然。

## What Changes

- 新增 Telegram Bot 服务，作为唯一的交互入口
- 新增动态 Prompt 组装系统：每次对话实时拼接人设、长期记忆、对话摘要、好感度、情绪状态
- 新增好感度系统（5 阶段制），影响称呼和行为模式，诺艾尔能感知自身好感度等级
- 新增情绪系统（开心/担心/寂寞/难过/生气/平静），自然衰减回平静，受对话内容和自主行为影响
- 新增长期记忆系统：结构化存储用户画像 + 对话摘要压缩
- 新增自主行为引擎（后续阶段）：定时浏览社交媒体，影响诺艾尔自身记忆和情绪，进而主动发起对话
- 新增图片理解能力（后续阶段）
- 技术栈：Python + LangChain + aiogram + OpenAI SDK（通过 LongCat 代理）

## Capabilities

### New Capabilities

- `chat`: 多轮文本对话，诺艾尔人设驱动，动态 Prompt 组装
- `affection`: 好感度系统，5 阶段制，受对话影响，影响称呼和行为底线
- `emotion`: 情绪系统，6 种状态，自然衰减，影响当下回复风格
- `memory`: 长期记忆系统，结构化用户画像 + 对话摘要压缩
- `autonomous-behavior`: 自主行为引擎，定时浏览社交媒体影响自身状态并主动发起对话
- `image-understanding`: 图片理解能力（后续阶段）

### Modified Capabilities

（无，这是一个全新项目）

## Impact

- **新增代码**：全新 Python 项目，无既有代码影响
- **新增依赖**：aiogram (Telegram Bot)、LangChain (LLM 编排)、OpenAI SDK (模型调用)、SQLite/文件存储 (记忆持久化)
- **外部服务**：LongCat (OpenAI 兼容 API 代理)、Telegram Bot API
- **部署**：本地开发 → 自有云服务器部署
- **用户**：单一用户（开发者本人），无需多租户设计
